# DEVELOPMENT & REPOSITORY GUIDE

## Local Setup

```bash
# 1. Clone the repository
git clone https://github.com/reginaldalfret/portfolio-website.git
cd portfolio-website

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Access the Next.js development server at `http://localhost:3000`.

## Building the Primary Portfolio
```bash
npm run build
npm run start
```

## Running the Polyglot Multi-Stack Tests
```bash
npm run test:stacks
```

## Validating Shared Content
```bash
npm run validate:content
```
