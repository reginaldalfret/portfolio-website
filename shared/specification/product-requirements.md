# 12 STACKS. 1 PRODUCT. — Product Requirements Specification

## 1. Overview
The Polyglot Portfolio Experiment is a production-grade engineering showcase demonstrating how 12 distinct programming frameworks across 11 programming languages can implement the exact same high-performance, responsive obsidian resume portfolio natively.

## 2. The 12 Implementations Lineup
1. **Next.js 14** (TypeScript / React 18 / Vercel Edge SSR)
2. **Nuxt 3** (TypeScript / Vue 3 / Nitro SSR)
3. **Django 6** (Python 3.13 / Django SSR Templates / MVT)
4. **Spring Boot 3** (Java 21 / Thymeleaf SSR / MVC)
5. **Laravel 11/12** (PHP 8.4 / Blade Templates / Artisan MVC)
6. **Ruby on Rails 8** (Ruby 3.4 / ActionView ERB / Puma)
7. **Angular 19/22** (TypeScript 6.0 / Standalone Signals / Vite SPA)
8. **Blazor WebAssembly** (.NET 8 / C# / Client-Side WASM)
9. **Go Buffalo** (Go 1.27 / Buffalo Plush SSR / Gorilla Mux)
10. **Leptos** (Rust 1.85 / WASM / Client-Side Reactive)
11. **Jaspr** (Dart 3.13 / Jaspr SSR & Web Hydration)
12. **Vapor 4** (Swift 6.0 / Leaf Templates / SwiftNIO SSR)

## 3. Product Functional Requirements
Every implementation must render and execute:
- Glassmorphic top command bar with view mode toggle (`Interactive Resume` vs `Original PDF Document`), Print trigger, and PDF Download trigger.
- Hero header with Reginald Alfret V's name, verified contact information (+91 81220 87088, LinkedIn, GitHub, email), and 4 key metric stats.
- ⚡ Open-Source Contributions section displaying all 30 merged PRs across tier-1 organizations (Apple, Google, Microsoft, Meta, AWS, NVIDIA, NASA, Netflix, Stripe) with working upstream links and badges.
- 2-Column interactive resume canvas detailing Professional Experience, Key Projects (301 Super AI Agents, TOR-UNVEIL, AI Crop Recommendation, Enterprise ERP), Technical Skills, Education, and Hackathon Honors.
- ⚡ Multi-Stack Architecture Showcase rendering all 12 cards, with the current engine actively highlighted and the remaining 11 offering one-click transitions and source code links.
- Interactive PDF previewer embedding `/Reginald_Alfret_Resume.pdf`.
- Mobile-optimized horizontal scrollable floating dock with all 12 stack links.
