## 🌟 The Core Vision

**The Polyglot Portfolio Experiment** is a signature engineering initiative proving how different technology ecosystems can implement the exact same production-quality, responsive obsidian developer portfolio natively.

Rather than building twelve superficial static pages or sharing one JavaScript frontend under different labels, each implementation is an independently built, idiomatically structured application respecting its framework's native rendering paradigm:

1. **Next.js 14** — React 18 · TypeScript · React Server Components (RSC) · Vercel Edge
2. **Nuxt 3** — Vue 3 · TypeScript · Nitro Engine · Universal SSR
3. **Django 6** — Python 3.13 · MVT Architecture · Pure Server-Side Rendering
4. **Spring Boot 3** — Java 21 · Thymeleaf SSR · Project Loom Virtual Threads
5. **Laravel 11/12** — PHP 8.4 · Blade Templates · FrankenPHP Worker Mode
6. **Ruby on Rails 8** — Ruby 3.4 · ActionView ERB · YJIT Runtime Acceleration
7. **Angular 19/22** — TypeScript 6.0 · Standalone Components · Signals SPA
8. **Blazor WebAssembly** — C# · .NET 8 · Client-Side WASM
9. **Go Buffalo** — Go 1.27 · Plush SSR · Native Compiled Binary
10. **Leptos 0.7** — Rust 1.85 · Wasm-Bindgen · Fine-Grained Reactive Signals
11. **Jaspr Web** — Dart 3.13 · Flutter Component Tree · Web Hydration
12. **Vapor 4** — Swift 6.0 · Leaf Templates · SwiftNIO Async EventLoops

## 🔬 The 12-Stack Engineering Laboratory

The live primary application at [reginaldalfret.tech](https://reginaldalfret.tech) features an interactive **12-Stack Engineering Lab & Benchmarking Dashboard**:
- **Interactive Filtering**: Filter by programming language (TypeScript, Python, Java, Go, Rust, Swift, etc.) and rendering strategy (SSR, SPA, WASM).
- **Side-by-Side Comparison Matrix**: Select two or more stacks to compare runtime, payload sizes, TTFB, and architecture.
- **Real Performance Benchmarking**: Standardized measurements across Lighthouse, First Contentful Paint (FCP), Largest Contentful Paint (LCP), and bundle sizes.
- **Architecture Visualizer**: Interactive Mermaid execution pipelines for every stack.
